Sitio Web - Parque Nacional Cahuita
Este proyecto consiste en un sitio web de una sola página (One Page) diseñado para presentar la información principal del Parque Nacional Cahuita en Limón, Costa Rica.

Contenido
Inicio: Bienvenida e introducción al parque.

Sobre el Parque: Historia, ubicación y biodiversidad.

Servicios y Actividades: Información de senderos, tours y atracciones.

Contacto: Datos de ubicación y formulario de consultas.

Tecnologías Utilizadas
HTML5: Estructura de la página y navegación por secciones.

CSS3: Diseños, colores y estilos visuales.
